# 평면과 공기 해상도를 분리한 SBSim 모델

기존 평면은 벽·창·공기·외기 경계의 위치를 정하는 데 사용한다. 열수지는 각 HVAC 존의 연결된 공기 영역을 대표 온도 하나로 풀 수 있게
한다. 더 자세히 풀 때는 영역을 최대 N×N 공기 CV 단위로 나눈다. 같은 블록에 있어도 벽으로 분리된 영역은 서로 묶이지 않는다.

1. 기존 SBSim 희소 열수지 행렬에서 공기 셀의 열용량과 열원을 합산한다. 서로 다른 노드 사이의 전도는 기존 경계면 열전도율의 합으로
    보존한다. 벽·창 셀은 개별 노드로 유지하고, 외부 복사와 일사 입력을 그대로 읽는다.
2. 축소 시스템을 CPU 희소 해법으로 푼다. 기존 HVAC와 벤치마크가 사용하는 관측에는 직전 존 평균과 같은 형식의 값을 제공한다. 실내
    축열 및 실내 장파 복사가 활성인 모델은 기존 솔버를 사용한다.
3. 실제로 꺾인 공기 영역과 벽으로 나뉜 영역을 테스트한다. L자 전체 평면의 5존과 100존 사무실에서 기존 전체 격자와 축소 모델을 같은
    행동으로 실행해 노드 수, 스텝 시간과 존 평균온도 차이를 함께 기록한다.
