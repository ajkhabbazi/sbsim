# 공통 VAV 모델의 RL 속도 비교 계획

1. EnergyPlus와 SBSim을 같은 TF-Agents 환경 규격으로 감싼다. 관측은 동일한 순서의 존 온도와 외기온, 행동은 전체 존의
    난방·냉방 설정온도 2개다. 양쪽의 고정 쾌적 온도 범위 초과분으로 같은 보상을 계산한다. 같은 EPW, 300초 스텝, 288스텝
    에피소드를 사용한다.
2. EnergyPlus는 스텝 시작 콜백에서 행동을 적용하고 스텝 종료 콜백에서 그 스텝의 온도를 읽는다. SBSim은 기존 온도조절기와
    `step_sim()`을 사용한다. 마지막 스텝과 다음 에피소드 리셋, 센서·액추에이터 연결, JAX 수렴을 확인한다.
3. 두 실행 모드를 비교한다. 고정 난수 시드의 동일 행동으로 실행하는 롤아웃은 시뮬레이터 호출 시간을 측정한다. SAC 실행은 기존
    네트워크·재생 버퍼 구성을 재사용하고 수집 스텝과 업데이트 수를 맞춘다. 첫 리셋, JAX 컴파일을 포함한 첫 스텝, 이후 스텝, 첫
    학습 업데이트, 이후 업데이트, 전체 시간을 별도로 기록한다.
4. 같은 CPU 코어에서 1·5·16존과 5존 세분 격자를 반복 실행한다. 엔진 실행 순서를 번갈아 적용하고 시드, 버전, 벤치마크 설정,
    반복별 실측치와 중앙값을 보존한다. 결과는 계산 속도에 한해 해석한다.

## 규모 확장

16·25·36·64·100존의 직사각형 방을 각각 4×4, 5×5, 6×6, 8×8, 10×10으로 배열한다. 방 크기 5×4 m, 층고 3
m, 벽 두께와 CV 0.5 m, 외벽 창 폭 2 m를 유지한다. 같은 날, CPU, 스텝 예산, 업데이트 예산으로 기존 벤치마크를 반복한다.
16존을 다시 측정해 앞선 실행과 같은 규모의 기준점을 두고, 반복 중앙값과 원본 기록을 보존한다.

## 외기와 재실 부하를 포함한 VAV 모델

기존 평면과 VAV 연결을 바탕으로 `office` 모델을 생성한다. 중앙 공조기에 시간대별 외기 혼합을 적용하고, 사무실·회의실·지원 공간의
재실·조명·플러그 부하를 공통 시간표로 정의한다. EnergyPlus는 외기 믹서와 부하 객체를 사용한다. SBSim은 같은 시간의 외기 비율과
존별 실내 현열을 사용한다. 에너지·온도 예측은 엔진의 물리 모델을 따른다. 16·100존의 하루 실행에서 외기와 부하가 실제로 변하는지
확인하고, 100존 기본 모델과 사무실 모델의 고정 행동 실행 시간을 비교한다.
